02 / FITS YOUR FLOW

설치하고, 바로 비교하세요.

전체 사용 가이드
GET STARTED
  1. 01

    운영체제에 맞는 버전 받기

    Windows는 최신 릴리스의 MSI 또는 포터블 EXE를 사용하세요. Mac은 DMG를 열고 rdiff를 Applications로 옮기세요.

  2. 02

    비교할 파일 연결하기

    앱의 파일 열기 기능을 사용하거나, 실행 파일 경로와 함께 오른쪽 명령어를 사용하세요.

  3. 03

    변경을 검토하고 저장하기

    필요한 변경을 적용한 후 저장하세요. 병합에서는 모든 충돌을 해결한 뒤 결과를 저장합니다.

WINDOWS / MACOS
두 파일 비교
rdiff diff "before.rs" "after.rs"
3-way 병합
rdiff merge "source.rs" "target.rs" "base.rs" "result.rs"

Windows는 .\rdiff.exe, macOS는 /Applications/rdiff.app/Contents/MacOS/rdiff를 사용하세요. PATH에 등록하면 위 명령어를 그대로 쓸 수 있습니다.

Diff 도구 인수
diff "%1" "%2"
Merge 도구 인수
merge "%1" "%2" "%b" "%r"

P4V의 외부 Diff / Merge 도구에 Windows는 rdiff.exe, macOS는 /Applications/rdiff.app/Contents/MacOS/rdiff의 전체 경로를 지정하세요. 인수 순서는 Source, Target, Base, Result입니다.

03 / GOOD TO KNOW

시작 전,
궁금한 것들.

이슈 남기기
어떤 파일과 운영체제를 지원하나요?+

Windows x64와 macOS 11 이상 Apple Silicon(M1 이후)을 지원합니다. Intel Mac용 빌드는 아직 제공하지 않습니다. 파일당 최대 2 MiB의 UTF-8 텍스트를 지원하며 UTF-8 BOM은 저장 시 유지합니다. 바이너리, UTF-16, 폴더 비교는 지원하지 않습니다.

MSI와 포터블 EXE는 어떻게 다른가요?+

MSI는 현재 사용자 계정에 설치되고 시작 메뉴에 바로가기를 만듭니다. 관리자 권한 없이 설치할 수 있으며 Windows 설치된 앱에서 제거할 수 있습니다. 포터블 EXE는 원하는 폴더에 두고 바로 실행할 수 있습니다.

Mac에서 설치하고 업데이트하려면 어떻게 하나요?+

DMG를 열어 rdiff.app을 Applications로 드래그한 뒤 실행하세요. 현재 Mac 배포본은 Apple 공증을 받지 않았습니다. 첫 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안에서 앱을 확인한 뒤 '그래도 열기'를 선택하세요. 자세한 절차는 Apple의 앱 실행 안내를 참고하세요. Mac 업데이트는 최신 DMG를 받아 앱을 교체하면 됩니다.

병합하면 원본 파일도 바뀌나요?+

3-way 병합에서는 Source, Target, Base를 입력으로 읽고 지정한 Result 경로에만 저장합니다. 자동 병합이 끝나도 저장 버튼을 누르기 전에는 결과 파일을 쓰지 않습니다. Result 경로는 보존할 입력 파일과 다르게 지정하세요.

업데이트와 소스 코드는 어디서 확인하나요?+

GitHub Releases에서 릴리스를 확인할 수 있습니다. Windows에서는 앱의 업데이트 확인 기능이나 rdiff self-update --check 명령도 사용할 수 있습니다. macOS는 최신 DMG로 직접 업데이트하세요. 소스 코드는 GitHub 저장소에서 MIT 라이선스로 공개합니다.
